## 🛠️ Local Development Setup

Want to run the gaming hub locally or contribute? Follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yourusername/unblockGames-2026.git
   ```
2. **Install dependencies:**
   ```bash
   npm install
   # or yarn install
   ```
3. **Start the development server:**
   ```bash
   npm run dev
   ```
4. Open `http://localhost:5173` in your browser.
